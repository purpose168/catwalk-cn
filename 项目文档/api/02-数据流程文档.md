# Catwalk CN 数据流程文档

## 概述

本文档详细说明了 Catwalk CN 中关键业务流程的数据流转，包括数据在各模块间的传递过程。

## 数据流程图

## 数据结构流转

### Provider 数据结构

```
JSON 配置文件
    │
    │ (Go embed)
    ▼
[]byte (嵌入的字节数据)
    │
    │ (json.Unmarshal)
    ▼
catwalk.Provider 结构
    │
    │ (添加到列表)
    ▼
[]catwalk.Provider
    │
    │ (json.Marshal)
    ▼
[]byte (providersJSON)
    │
    │ (etag.Of)
    ▼
string (providersETag)
    │
    │ (HTTP 响应)
    ▼
客户端 JSON 数据
```

### Model 数据结构

```
JSON 配置文件 (在 Provider 中)
    │
    │ (Go embed)
    ▼
[]byte (嵌入的字节数据)
    │
    │ (json.Unmarshal)
    ▼
catwalk.Model 结构
    │
    │ (添加到 Provider.Models)
    ▼
[]catwalk.Model
    │
    │ (json.Marshal)
    ▼
[]byte (providersJSON)
    │
    │ (HTTP 响应)
    ▼
客户端 JSON 数据
```

```
┌─────────────────────────────────────────────────────────────────┐
│              首次请求                              │

└─────────────────────────────────────────────────────────────────┘
                            │
                            ▼
┌─────────────────────────────────────────────────────────────────┐
│              检查 ETag                              │

└─────────────────────────────────────────────────────────────────┘
                            │
                            ▼
┌─────────────────────────────────────────────────────────────────┐
│              返回完整数据                            │
│  Status: 200 OK                                                │

│  Body: [providers]                                             │
└─────────────────────────────────────────────────────────────────┘
                            │
                            ▼
┌─────────────────────────────────────────────────────────────────┐
│              客户端缓存                              │
│  保存 ETag 和数据                                               │
└─────────────────────────────────────────────────────────────────┘
                            │
                            ▼
┌─────────────────────────────────────────────────────────────────┐
│              后续请求                              │
│  GET /v2/providers                                             │
│  If-None-Match: "33a64df551425fcc55e4d42a148795d9f25f89d4"    │
└─────────────────────────────────────────────────────────────────┘
                            │
                            ▼
┌─────────────────────────────────────────────────────────────────┐
│              检查 ETag                              │
│  etag.Matches(r, providersETag) = true                        │
└─────────────────────────────────────────────────────────────────┘
                            │
                            ▼
┌─────────────────────────────────────────────────────────────────┐
│              返回 304 Not Modified                   │
│  Status: 304 Not Modified                                       │
│  Body: 空                                                       │
└─────────────────────────────────────────────────────────────────┘
                            │

┌─────────────────────────────────────────────────────────────────┐
│              客户端使用缓存                          │

```

## 总结

Catwalk CN 的数据流程清晰而高效：

1. **初始化流程**: 加载配置、生成 ETag、启动服务器
2. **请求处理流程**: 检查缓存、处理请求、返回响应
3. **缓存流程**: 使用 ETag 实现客户端缓存
4. **监控流程**: 收集和暴露 Prometheus 指标
5. **错误处理流程**: 记录错误、返回适当响应

这种数据流程设计使得 Catwalk CN 成为一个可靠、高效且易于监控的 AI 提供商数据库服务。
