## Docker 构建

### Dockerfile

```dockerfile
# 构建阶段
FROM golang:1.25.5-alpine AS builder

WORKDIR /app

# 复制依赖文件
COPY go.mod go.sum ./
RUN go mod download

# 复制源代码
COPY . .

# 构建应用
RUN CGO_ENABLED=0 GOOS=linux go build -a -installsuffix cgo -o catwalk-cn .

# 运行阶段
FROM alpine:latest

RUN apk --no-cache add ca-certificates

WORKDIR /root/

# 从构建阶段复制二进制文件
COPY --from=builder /app/catwalk-cn .

# 暴露端口
EXPOSE 8080

# 运行应用
CMD ["./catwalk-cn"]
```

### 构建镜像

```bash
docker build -t catwalk-cn:latest .
```

### 运行容器

```bash
docker run -p 8080:8080 catwalk-cn:latest
```

## 部署流程

### 本地部署

#### 1. 构建

```bash
make compile
```

#### 2. 运行

```bash
./build/catwalk-cn
```

#### 3. 验证

```bash
curl http://localhost:8080/healthz
```

### 服务器部署

#### 1. 上传二进制文件

```bash
scp build/catwalk-cn user@server:/opt/catwalk-cn/
```

#### 2. 创建 systemd 服务

创建 `/etc/systemd/system/catwalk-cn.service`：

```ini
[Unit]
Description=Catwalk CN Service
After=network.target

[Service]
Type=simple
User=catwalk
WorkingDirectory=/opt/catwalk-cn
ExecStart=/opt/catwalk-cn/catwalk-cn
Restart=always
RestartSec=5
StandardOutput=journal
StandardError=journal

[Install]
WantedBy=multi-user.target
```

#### 3. 启动服务

```bash
sudo systemctl daemon-reload
sudo systemctl enable catwalk-cn
sudo systemctl start catwalk-cn
```

#### 4. 检查状态

```bash
sudo systemctl status catwalk-cn
```

#### 5. 查看日志

```bash
sudo journalctl -u catwalk-cn -f
```

### Docker 部署

#### 1. 构建镜像

```bash
docker build -t catwalk-cn:latest .
```

#### 2. 运行容器

```bash
docker run -d \
  --name catwalk-cn \
  -p 8080:8080 \
  --restart unless-stopped \
  catwalk-cn:latest
```

#### 3. 验证

```bash
curl http://localhost:8080/healthz
```

### Kubernetes 部署

#### 1. 创建 Deployment

创建 `deployment.yaml`：

```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: catwalk-cn
spec:
  replicas: 3
  selector:
    matchLabels:
      app: catwalk-cn
  template:
    metadata:
      labels:
        app: catwalk-cn
    spec:
      containers:
      - name: catwalk-cn
        image: catwalk-cn:latest
        ports:
        - containerPort: 8080
        livenessProbe:
          httpGet:
            path: /healthz
            port: 8080
          initialDelaySeconds: 10
          periodSeconds: 10
        readinessProbe:
          httpGet:
            path: /healthz
            port: 8080
          initialDelaySeconds: 5
          periodSeconds: 5
        resources:
          requests:
            memory: "64Mi"
            cpu: "100m"
          limits:
            memory: "128Mi"
            cpu: "200m"
```

#### 2. 创建 Service

创建 `service.yaml`：

```yaml
apiVersion: v1
kind: Service
metadata:
  name: catwalk-cn
spec:
  selector:
    app: catwalk-cn
  ports:
  - protocol: TCP
    port: 80
    targetPort: 8080
  type: LoadBalancer
```

#### 3. 部署

```bash
kubectl apply -f deployment.yaml
kubectl apply -f service.yaml
```

#### 4. 验证

```bash
kubectl get pods
kubectl get svc
```

## 环境变量配置

Catwalk CN 本身不需要环境变量，但配置文件中使用了环境变量占位符：

```json
{
  "api_key": "$OPENAI_API_KEY",
  "api_endpoint": "$OPENAI_API_ENDPOINT"
}
```

这些占位符由客户端处理，Catwalk CN 不进行替换。

### 可选环境变量

| 变量 | 说明 | 默认值 |
|------|------|--------|
| `PORT` | 监听端口 | `8080` |
| `HOST` | 监听地址 | `:8080` |

## 反向代理配置

### Nginx

```nginx
upstream catwalk_cn {
    server localhost:8080;
}

server {
    listen 80;
    server_name catwalk.example.com;

    location / {
        proxy_pass http://catwalk_cn;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
```

### Caddy

```caddyfile
catwalk.example.com {
    reverse_proxy localhost:8080
}
```

## 日志管理

### 日志级别

Catwalk CN 使用标准 `log` 包，日志级别为 `Info`。

### 日志输出

日志输出到标准输出（stdout），便于容器化部署。

### 日志收集

使用 Docker 或 Kubernetes 的日志收集机制：

```bash
# Docker
docker logs -f catwalk-cn

# Kubernetes
kubectl logs -f deployment/catwalk-cn
```

## 性能优化

### 缓存

Catwalk CN 使用 ETag 实现客户端缓存，无需额外配置。

### 并发

Go HTTP 服务器原生支持并发，无需额外配置。

### 压缩

建议在反向代理层启用 gzip 压缩。

## 备份与恢复

### 备份

Catwalk CN 不需要备份，配置文件编译到二进制中。

### 恢复

重新部署二进制文件即可。

curl http://localhost:8080/healthz
