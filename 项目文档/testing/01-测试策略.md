# Catwalk CN 测试策略

## 概述

本文档明确了 Catwalk CN 项目的单元测试、集成测试、系统测试的实施方法及测试工具使用规范。

## 测试原则

### 测试金字塔

```
        /\
       /  \
      / E2E \      (少量)
     /--------\
    / 集成测试 \    (适量)
   /------------\
  /   单元测试    \  (大量)
 /----------------\
```

- **单元测试**: 测试单个函数和方法
- **集成测试**: 测试模块间的交互
- **E2E 测试**: 测试完整的用户流程

### 测试覆盖率

- 目标覆盖率: 80%+
- 核心模块: 90%+
- 工具函数: 100%

## 单元测试

### 测试框架

使用 Go 标准库 `testing` 包。

### 测试文件命名

测试文件命名为 `*_test.go`，与被测试文件在同一目录。

```
providers/
├── providers.go
└── providers_test.go
```

### 测试函数命名

测试函数命名格式：`Test<FunctionName>`

```go
func TestGetAll(t *testing.T) {
    // 测试代码
}
```

### 表驱动测试

使用表驱动测试测试多个场景：

```go
func TestGetAll(t *testing.T) {
    tests := []struct {
        name     string
        expected int
    }{
        {"should return all providers", 21},
        {"should return non-empty list", 21},
    }

    for _, tt := range tests {
        t.Run(tt.name, func(t *testing.T) {
            providers := GetAll()
            if len(providers) != tt.expected {
                t.Errorf("expected %d providers, got %d", tt.expected, len(providers))
            }
        })
    }
}
```

### Mock 测试

使用接口和 mock 进行测试：

```go
type MockProviderFunc func() Provider

func TestLoadProviderFromConfig(t *testing.T) {
    configData := []byte(`{
        "name": "Test Provider",
        "id": "test",
        "type": "openai"
    }`)

    provider := loadProviderFromConfig(configData)
    
    if provider.Name != "Test Provider" {
        t.Errorf("expected name 'Test Provider', got '%s'", provider.Name)
    }
}
```

### 测试辅助函数

使用 `testing.T` 的辅助方法：


## 集成测试

### HTTP 端点测试

使用 `net/http/httptest` 测试 HTTP 端点：

```go
func TestProvidersHandler(t *testing.T) {
    tests := []struct {
        name           string
        method         string
        expectedStatus int
        expectedType   string
    }{
        {"GET request", "GET", http.StatusOK, "application/json"},
        {"POST request", "POST", http.StatusMethodNotAllowed, ""},
    }

    for _, tt := range tests {
        t.Run(tt.name, func(t *testing.T) {
            req := httptest.NewRequest(tt.method, "/v2/providers", nil)
            w := httptest.NewRecorder()

            providersHandler(w, req)

            if w.Code != tt.expectedStatus {
                t.Errorf("expected status %d, got %d", tt.expectedStatus, w.Code)
            }

            if tt.expectedType != "" {
                contentType := w.Header().Get("Content-Type")
                if contentType != tt.expectedType {
                    t.Errorf("expected Content-Type %s, got %s", tt.expectedType, contentType)
                }
            }
        })
    }
}
```

### ETag 测试

测试 ETag 缓存行为：

```go
func TestProvidersHandlerETag(t *testing.T) {
    req := httptest.NewRequest("GET", "/v2/providers", nil)
    w := httptest.NewRecorder()

    providersHandler(w, req)

    etag := w.Header().Get("Etag")
    if etag == "" {
        t.Fatal("expected ETag header")
    }

    req = httptest.NewRequest("GET", "/v2/providers", nil)
    req.Header.Set("If-None-Match", etag)
    w = httptest.NewRecorder()

    providersHandler(w, req)

    if w.Code != http.StatusNotModified {
        t.Errorf("expected status 304, got %d", w.Code)
    }
}
```

### 健康检查测试

```go
func TestHealthzHandler(t *testing.T) {
    req := httptest.NewRequest("GET", "/healthz", nil)
    w := httptest.NewRecorder()

    healthzHandler(w, req)

    if w.Code != http.StatusOK {
        t.Errorf("expected status 200, got %d", w.Code)
    }

    body := w.Body.String()
    if body != "OK" {
        t.Errorf("expected body 'OK', got '%s'", body)
    }
}
```

## 系统测试

### 端到端测试

使用真实 HTTP 服务器进行测试：

```go
func TestE2E(t *testing.T) {
    // 启动测试服务器
    server := httptest.NewServer(http.HandlerFunc(providersHandler))
    defer server.Close()

    // 发送请求
    resp, err := http.Get(server.URL + "/v2/providers")
    if err != nil {
        t.Fatal(err)
    }
    defer resp.Body.Close()

    // 验证响应
    if resp.StatusCode != http.StatusOK {
        t.Errorf("expected status 200, got %d", resp.StatusCode)
    }

    var providers []Provider
    if err := json.NewDecoder(resp.Body).Decode(&providers); err != nil {
        t.Fatal(err)
    }

    if len(providers) == 0 {
        t.Error("expected non-empty providers list")
    }
}
```

## 测试最佳实践

### 1. 测试独立性

每个测试应该独立运行，不依赖其他测试：

```go
func TestProvider1(t *testing.T) {
    // 独立设置
    provider := createTestProvider()
    
    // 测试逻辑
    // ...
}

func TestProvider2(t *testing.T) {
    // 独立设置
    provider := createTestProvider()
    
    // 测试逻辑
    // ...
}
```

### 2. 测试可读性

测试名称应该清晰描述测试内容：

```go
// 好的测试名称
func TestGetAll_ReturnsCorrectNumberOfProviders(t *testing.T) {
    // ...
}

// 不好的测试名称
func TestGetAll(t *testing.T) {
    // ...
}
```

### 3. 测试完整性

测试应该覆盖正常和异常情况：

```go
func TestLoadProviderFromConfig(t *testing.T) {
    tests := []struct {
        name        string
        configData  []byte
        expectError bool
    }{
        {"valid config", []byte(`{"name": "Test"}`), false},
        {"invalid JSON", []byte(`{invalid}`), true},
        {"empty config", []byte(`{}`), false},
    }

    for _, tt := range tests {
        t.Run(tt.name, func(t *testing.T) {
            provider := loadProviderFromConfig(tt.configData)
            
            if tt.expectError && provider.Name != "" {
                t.Error("expected error, got provider")
            }
        })
    }
}
```

### 4. 测试维护

定期更新测试，保持测试与代码同步。

## 持续集成

### CI 配置

使用 GitHub Actions 进行持续集成：

```yaml
name: CI

on:
  push:
    branches: [ main ]
  pull_request:
    branches: [ main ]

jobs:
  test:
    runs-on: ubuntu-latest
    
    steps:
    - uses: actions/checkout@v3
    
    - name: Set up Go
      uses: actions/setup-go@v4
      with:
        go-version: '1.25.5'
    
    - name: Install dependencies
      run: go mod download
    
    - name: Run tests
      run: go test -v -cover ./...
    
    - name: Run linter
      uses: golangci/golangci-lint-action@v3
      with:
        version: latest
```

### 测试报告

生成测试报告并上传到 CI：

```yaml
- name: Generate coverage report
  run: |
    go test -coverprofile=coverage.out ./...
    go tool cover -html=coverage.out -o coverage.html

- name: Upload coverage report
  uses: actions/upload-artifact@v3
  with:
    name: coverage-report
    path: coverage.html
```
