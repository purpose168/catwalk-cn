# Catwalk CN 技术栈说明

## 概述

Catwalk CN 是一个基于 Go 语言开发的 AI 推理提供商数据库服务，提供 RESTful API 接口供客户端查询 AI 提供商和模型信息。本文档详细说明了项目使用的技术组件及其版本信息。

## HTTP 服务器

### 标准库

Catwalk CN 使用 Go 标准库 `net/http` 实现 HTTP 服务器。

**特性**:
- 高性能
- 内置路由
- 支持中间件
- 超时控制

**配置**:
```go
server := &http.Server{
    Addr:         ":8080",
    Handler:      mux,
    ReadTimeout:  15 * time.Second,
    WriteTimeout: 15 * time.Second,
    IdleTimeout:  60 * time.Second,
}
```

### 路由

使用 `http.ServeMux` 实现路由。

**端点**:
- `/v2/providers` - 获取所有提供商（v2版本）
- `/providers` - 获取所有提供商（已弃用）
- `/healthz` - 健康检查
- `/metrics` - Prometheus 指标

## 监控

### Prometheus

Catwalk CN 集成 Prometheus 进行监控。

**指标**:
- `catwalk_providers_requests_total` - 提供商端点请求总数

**端点**:
- `/metrics` - Prometheus 指标端点

**集成**:
```go
import (
    "github.com/prometheus/client_golang/prometheus"
    "github.com/prometheus/client_golang/prometheus/promauto"
    "github.com/prometheus/client_golang/prometheus/promhttp"
)

var counter = promauto.NewCounter(prometheus.CounterOpts{
    Namespace: "catwalk",
    Subsystem: "providers",
    Name:      "requests_total",
    Help:      "Total number of requests to providers endpoint",
})

mux.Handle("/metrics", promhttp.Handler())
```

## 缓存

### ETag

Catwalk CN 使用 ETag 实现客户端缓存。

**库**: `github.com/purpose168/charm-experimental-packages-cn/etag`

**实现**:
```go
import "github.com/purpose168/charm-experimental-packages-cn/etag"

// 生成 ETag
providersETag = etag.Of(providersJSON)

// 检查 ETag
if etag.Matches(r, providersETag) {
    w.WriteHeader(http.StatusNotModified)
    return
}

// 设置 ETag
etag.Response(w, providersETag)
```

**优势**:
- 减少网络传输
- 降低服务器负载
- 提高响应速度

### Go Embed

使用 Go 1.16+ 的 embed 功能嵌入配置文件。

**实现**:
```go
import _ "embed"

//go:embed configs/openai.json
var openAIConfig []byte

//go:embed configs/anthropic.json
var anthropicConfig []byte
```

**优势**:
- 配置文件编译到二进制中
- 无需外部文件
- 简化部署

## 安全性

### 输入验证

Catwalk CN 不执行用户输入，只提供只读 API。

### 环境变量

配置文件中使用环境变量占位符：

```json
{
  "api_key": "$OPENAI_API_KEY",
  "api_endpoint": "$OPENAI_API_ENDPOINT"
}
```

**注意**: Catwalk CN 本身不替换环境变量，由客户端处理。

### HTTPS

建议在生产环境中使用反向代理（如 Nginx）提供 HTTPS 支持。

## 总结

Catwalk CN 的技术栈简洁而强大：

1. **纯 Go 实现**: 无外部语言依赖
2. **跨平台**: 支持 Linux、macOS、Windows
3. **最小依赖**: 只依赖必要的库
4. **高性能**: 原生 Go HTTP 服务器
5. **生产就绪**: 集成 Prometheus 监控
6. **易于部署**: 单一二进制文件

这种技术栈选择使得 Catwalk CN 成为一个可靠、高效且易于维护的 AI 提供商数据库服务。
