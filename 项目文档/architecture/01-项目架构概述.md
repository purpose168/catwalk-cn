# Catwalk CN 项目架构概述

## 概述

Catwalk CN 是一个 AI 推理提供商和模型的数据库服务，为 Crush 项目提供模型配置信息。本项目是对 [Charmbracelet/Catwalk](https://github.com/charmbracelet/catwalk) 的中文本地化衍生版本，保留了原始框架的核心功能，同时提供了中文文档和注释。

## 架构设计

### 核心组件

#### 1. HTTP 服务层

**职责**: 处理 HTTP 请求和响应

**核心文件**: `main.go`

**主要功能**:
- 启动 HTTP 服务器
- 路由请求到处理器
- 配置超时和连接参数

**配置**:
```go
server := &http.Server{
    Addr:         ":8080",
    Handler:      mux,
    ReadTimeout:  15 * time.Second,
    WriteTimeout: 15 * time.Second,
    IdleTimeout:  60 * time.Second,
}
```

#### 2. 路由处理器

**职责**: 处理不同的 HTTP 端点

**端点列表**:

| 端点 | 方法 | 说明 |
|--------|--------|------|
| `/v2/providers` | GET | 获取所有提供商（v2版本） |
| `/providers` | GET | 获取所有提供商（已弃用） |
| `/healthz` | GET | 健康检查 |
| `/metrics` | GET | Prometheus 指标 |

#### 3. 提供商管理器

**职责**: 管理所有 AI 提供商配置

**核心文件**: `internal/providers/providers.go`

**主要功能**:
- 注册所有提供商
- 加载提供商配置
- 返回提供商列表

**提供商注册**:
```go
var providerRegistry = []ProviderFunc{

```

#### 4. 配置加载器

**职责**: 从 JSON 文件加载提供商配置

**核心文件**: `internal/providers/providers.go`

**主要功能**:
- 使用 Go embed 嵌入配置文件
- 解析 JSON 配置
- 返回 Provider 结构

**配置嵌入**:
```go
//go:embed configs/openai.json
var openAIConfig []byte

//go:embed configs/anthropic.json
var anthropicConfig []byte
```

#### 5. 监控层

**职责**: 收集和暴露 Prometheus 指标

**主要功能**:
- 统计请求总数
- 暴露指标端点
- 支持 ETag 缓存

**指标定义**:
```go
var counter = promauto.NewCounter(prometheus.CounterOpts{
    Namespace: "catwalk",
    Subsystem: "providers",
    Name:      "requests_total",
    Help:      "Total number of requests to providers endpoint",
})
```

## 数据模型

### Provider 结构

```go
type Provider struct {
    Name                string            // 提供商名称
    ID                  InferenceProvider // 推理提供商ID
    APIKey              string            // API密钥
    APIEndpoint         string            // API端点地址
    Type                Type              // 类型
    DefaultLargeModelID string            // 默认大模型ID
    DefaultSmallModelID string            // 默认小模型ID
    Models              []Model           // 模型列表
    DefaultHeaders      map[string]string // 默认请求头
}
```

### Model 结构

```go
type Model struct {
    ID                     string       // 模型ID
    Name                   string       // 模型名称
    CostPer1MIn            float64      // 每百万输入token的成本
    CostPer1MOut           float64      // 每百万输出token的成本
    CostPer1MInCached      float64      // 每百万缓存输入token的成本
    CostPer1MOutCached     float64      // 每百万缓存输出token的成本
    ContextWindow          int64        // 上下文窗口大小
    DefaultMaxTokens       int64        // 默认最大token数
    CanReason              bool         // 是否支持推理
    ReasoningLevels        []string     // 推理级别列表
    DefaultReasoningEffort string       // 默认推理努力值
    SupportsImages         bool         // 是否支持图片附件
    Options                ModelOptions // 模型配置选项
}
```

## 缓存策略

### ETag 缓存

Catwalk CN 使用 ETag 实现客户端缓存：

```go
// 生成 ETag
providersETag = etag.Of(providersJSON)

// 检查 ETag
if etag.Matches(r, providersETag) {
    w.WriteHeader(http.StatusNotModified)
    return
}
```

**优势**:
- 减少网络传输
- 降低服务器负载
- 提高响应速度

## 扩展性设计

### 添加新提供商

1. 创建配置文件 `internal/providers/configs/<provider>.json`
2. 在 `providers.go` 中添加 embed 指令
3. 添加 ProviderFunc 到 registry
4. 重新构建和部署

### 添加新模型

在对应提供商的配置文件中添加模型定义。

## 总结

Catwalk CN 的架构设计简洁而高效：

1. **HTTP 服务**: 提供 RESTful API
2. **配置管理**: 使用 JSON 文件和 Go embed
3. **缓存策略**: ETag 实现
4. **监控支持**: Prometheus 指标
5. **易于扩展**: 添加新提供商简单

这种架构使得 Catwalk CN 成为一个可靠、高效且易于维护的 AI 提供商数据库服务。
