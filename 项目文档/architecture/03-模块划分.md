# Catwalk CN 模块划分

## 概述

Catwalk CN 项目采用模块化设计，将功能划分为清晰的模块，每个模块负责特定的职责。本文档详细说明了项目的模块划分及其职责。

## 核心模块

### 1. HTTP 服务模块

**文件**: `main.go`

**职责**:
- 启动和管理 HTTP 服务器
- 处理 HTTP 请求和响应
- 配置超时和连接参数
- 路由请求到处理器

**核心结构**:
```go
type Server struct {
    Addr         string        // 监听地址
    Handler      http.Handler  // 请求处理器
    ReadTimeout  time.Duration // 读取超时
    WriteTimeout time.Duration // 写入超时
    IdleTimeout  time.Duration // 空闲超时
}
```

**主要功能**:
- 启动 HTTP 服务器
- 路由请求到处理器
- 处理健康检查
- 暴露 Prometheus 指标

### 2. 路由处理模块

**文件**: `main.go`

**职责**:
- 处理不同的 HTTP 端点
- 实现 ETag 缓存
- 统计请求指标
- 返回 JSON 响应

**核心函数**:

#### providersHandler

```go
func providersHandler(w http.ResponseWriter, r *http.Request)
```

**职责**:
- 处理 `/v2/providers` 端点
- 检查 ETag 缓存
- 增加请求计数器
- 返回提供商列表

#### providersHandlerDeprecated

```go
func providersHandlerDeprecated(w http.ResponseWriter, r *http.Request)
```

**职责**:
- 处理 `/providers` 端点（已弃用）
- 返回所有提供商配置
- 兼容旧版本客户端

#### healthzHandler

```go
func healthzHandler(w http.ResponseWriter, r *http.Request)
```

**职责**:
- 处理 `/healthz` 端点
- 返回健康状态
- 用于负载均衡器健康检查

### 3. 提供商管理模块

**文件**: `internal/providers/providers.go`

**职责**:
- 管理所有 AI 提供商配置
- 加载和解析 JSON 配置
- 注册和检索提供商
- 提供提供商列表

**核心结构**:

#### ProviderFunc

```go
type ProviderFunc func() catwalk.Provider
```

**职责**: 提供商构造函数类型

```go

```

**职责**: 存储所有注册的提供商构造函数

**主要方法**:

#### GetAll

```go

```

**职责**:


## 模块交互

### 初始化流程

```
1. main.go
    │
    ├── 初始化 providersJSON
    │   ├── 调用 providers.GetAll()
    │   │   ├── 遍历 providerRegistry
    │   │   ├── 调用每个 ProviderFunc
    │   │   └── 返回 Provider 列表
    │   │
    │   └── json.Marshal(providers)
    │
    ├── 生成 providersETag
    │   └── etag.Of(providersJSON)
    │
    └── 创建 HTTP Server
```

### 请求处理流程

```
1. HTTP 请求
    │
    ├── 路由到处理器
    │
    ├── providersHandler
    │   ├── 检查 ETag
    │   ├── 增加计数器
    │   ├── 返回 JSON
    │   └── 设置 ETag
    │
    └── healthzHandler
        └── 返回 OK
```

## 总结

Catwalk CN 的模块划分清晰而合理：

1. **职责分离**: 每个模块有明确的职责
2. **低耦合**: 模块间通过接口交互
3. **高内聚**: 相关功能集中在同一模块
4. **易于扩展**: 可以轻松添加新提供商
5. **易于测试**: 模块可以独立测试

这种模块化设计使得 Catwalk CN 成为一个易于理解、维护和扩展的 AI 提供商数据库服务。
